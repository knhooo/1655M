# 플레이테스트 체크리스트 (9/1 저녁 or 9/2 아침)

**치트 OFF** 상태로. (`1655M/Debug: Player Invincible` 해제, `Debug: All Swords Unlocked` 해제)

## 코어 루프 (필수 통과)

- [ ] 타이틀 → Ready 버튼 → 인벤토리 슬라이드다운
- [ ] Status 탭: 강화 팝업, 재화 부족 시 버튼 비활성, 강화 시 요약(Damage/HP/SwordDmg) 갱신
- [ ] Sword 탭: 스크롤, 아이콘 클릭 → 치확 표시, SELECT → 장착, 장착 중이면 SELECT 비활성
- [ ] Play 버튼 → 하강 시작
- [ ] 5방향 이동 = 채굴, 흙 1타 / 암반 여러타 / 광맥 최다타
- [ ] 지층 접촉 피해 (좌/우/아래 인접)
- [ ] 스킬 3종: Z/X/C + UI 버튼, 쿨다운 fill, 대시 버튼 안 깜빡이는지
- [ ] 편대 3종 등장 (가로/피라미드/상자가드)
- [ ] 상자 파괴 → 재화 or 검, 재화 광맥 인접 자동 수확
- [ ] 적 처치 → 코인 + 위로 튕겨 화면 밖 소멸
- [ ] 블록 파괴 → 파편 튕김
- [ ] HP 낮을 때 화면 빨강 비네트, HP 바 흰 플래시
- [ ] 사망 → 카메라 되감기 → 결과(점수/최고/재화) → 페이드 → 타이틀
- [ ] 재도전 시 강화·장착 유지, 재화 누적됨

## 보스 A (중간 심도)

- [ ] 진입 통로(가운데 세로 5칸)로 낙하 → 보스 위 착지
- [ ] **한 대 때리기 전엔 공격 안 함** (관찰 중엔 조용)
- [ ] 첫 타격 후 HP 바 등장 + 공격 개시
- [ ] 경고 마커 깜빡임 (끝에 빨라짐) → 강타
- [ ] 세로 강타: 머리 위부터, 충격파 아래→위 순차
- [ ] 가로 강타: 듬성듬성(oxox), 안전지대 매번 위치 바뀜, 충격파 왼→오
- [ ] 강타가 **지층/일반 적은 안 부순다** (플레이어만 피해)
- [ ] 처치 → 9x9 사라지며 하강 재개, 코인

## 보스 B (최종 심도)

- [ ] 파이어볼: 머리에서 대각선 위 발사, 4벽 튕김, **플레이어 닿아도 안 사라짐** (0.8s 간격 재피해)
- [ ] 토네이도: 세로 라인 경고 → 거기 있으면 붕 떴다가 착지 (조작 불가), 프리팹 있으면 작→커짐→작아짐
- [ ] **HP 절반 → 페이즈 2**: 파이어볼 양쪽 동시, 토네이도 여러 라인
- [ ] 처치 → 런 클리어

## 밸런스 — 특히 볼 것

- [ ] **보스 접촉 피해 DPS 레이스** — 보스와 붙어 싸우는 동안 접촉 40/s + 강타 60. 플레이어 HP 1000, 보스 HP 3000. 너무 빡빡하거나 너무 쉽지 않은지. (`Boss._contactDamage` / `_maxHp` / `_attackDamage` / `_contactInterval` 조절)
- [ ] **파이어볼 수직 공간** — 플레이어가 보스 머리 0.5칸 위에 서 있어서 파이어볼 상자 하단에 가깝다. 피할 여유가 있는지. 없으면 `Boss2._fireballCeiling` ↑ 또는 `Fireball._speed` ↓
- [ ] 재화 경제: 한 런에 강화 1~2회 가능한지 (드롭량 / 강화 비용)
- [ ] 지층 접촉 피해 5/16/27이 심도 대비 적절한지
- [ ] 스킬 쿨다운/효과 반경

## 알려진 엣지 (재현되면 메모, 아니면 무시)

- 돌진 중 토네이도 → 이번엔 토네이도 흘림 (의도된 방어 코드)
- 지형 유지 심도 300 초과 시 맨 위 오래된 행 회수 (되감기 때 상단 일부 빈 공간)
- 파이어볼/토네이도 VFX는 풀링 없이 Instantiate/Destroy (수 적어 무해)
